# Maquetado web institucional

Maquetado estático realizado con **HTML + CSS + JavaScript**, inspirado visualmente en las capturas proporcionadas. El proyecto usa una paleta morado/magenta y contiene información simulada para cada apartado.

## Archivos

- `index.html` — estructura de la página y contenido.
- `styles.css` — diseño visual, responsive y modo claro.
- `script.js` — navegación entre secciones, formularios simulados, tabla editable y gráficos.

## Ejecutar en tu computadora

### Opción 1: abrir directamente
Haz doble clic en `index.html`.

### Opción 2: VS Code + Live Server
1. Abre la carpeta del proyecto en VS Code.
2. Instala la extensión **Live Server**.
3. Haz clic derecho sobre `index.html`.
4. Selecciona **Open with Live Server**.
5. El navegador abrirá la página en una dirección local similar a `http://127.0.0.1:5500/`.

## Publicar gratis con GitHub Pages

1. Crea una cuenta en GitHub.
2. Crea un repositorio nuevo.
3. Para una página de usuario, el repositorio puede llamarse `TUUSUARIO.github.io`. También puedes usar un repositorio normal para una página de proyecto.
4. Sube `index.html`, `styles.css`, `script.js` y este `README.md`.
5. En el repositorio entra a **Settings > Pages**.
6. En **Build and deployment**, selecciona **Deploy from a branch**.
7. Selecciona la rama `main` y la carpeta `/ (root)` y guarda.
8. GitHub Pages publicará el contenido del repositorio. La publicación puede tardar algunos minutos.

### Importante
Este proyecto es un **sitio estático**: los formularios, altas y eliminaciones son simulaciones del lado del navegador. GitHub Pages no ejecuta PHP, Python o Node.js en el servidor. Si posteriormente necesitas usuarios reales, base de datos, autenticación o guardar evidencias, necesitarás un backend o un servicio externo.

## Datos del proyecto

Los nombres, indicadores y cantidades que aparecen en la interfaz son demostrativos y deben reemplazarse por datos reales antes de usar el sitio en un entorno institucional.
